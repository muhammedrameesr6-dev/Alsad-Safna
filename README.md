## Features

- **Paper Texture & Arabesque Backgrounds**: Islamic geometric patterns and subtle paper-textured gradients.
- **Floral Corner Accents**: High-resolution corner floral artwork with multiply blend mode.
- **Falling Petals Animation**: Organic floating flower petals with randomized drift, delays, and opacities.
- **Scroll Reveal Animations**: Smooth entry animations using Intersection Observer.
- **Interactive "Open Invitation" Flow**: Unfolds the invitation sections with smooth auto-scroll.
- **Bismillah & Quranic Duas**: Authentic Arabic typography rendered with the Amiri font.
- **Live Countdown Timer**: Real-time days, hours, minutes, and seconds countdown to the wedding ceremony.
- **Venue & Google Maps Embed**: Direct Google Maps embed and link for driving directions to Ayisha Convention Centre, Mylapore, Kollam.
- **Background Music with Audio Controller**: Turkish/Islamic wedding instrumental (`anlatmam.mp3`) with autoplay on interaction and floating mute/unmute controller.
- **Mobile Responsive**: Fully responsive design with mobile navigation drawer.

## Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build:

```bash
npm run build
npm run start
```
